## 🚀 Швидкий старт

> **Потрібно:** Node.js ≥ 20 і токен від [@BotFather](https://t.me/BotFather).

```bash
git clone https://github.com/TegarTheGreat/SotongAssistant.git
cd SotongAssistant
cp .env.example .env        # заповніть BOT_TOKEN і OWNER_ID
npm install
npm run dev                 # або: npm start
```

Далі в Telegram:

1. **Напишіть боту в особисті** → `/setkey anthropic sk-ant-…` (лише власник; повідомлення одразу видаляється, ключ зберігається зашифрованим).
2. **Додайте бота в групу** та зробіть **адміном** (видалення повідомлень, обмеження, запрошення, закріплення). Без прав адміна бот не бачить усі повідомлення (privacy mode).
3. У групі: `/settings` — усе, `/aimodel` — вибір моделі ШІ.
4. *(Опційно)* **Business**: під'єднайте в *Налаштування → Telegram Business → Чат-боти*.

### Конфігурація

| Змінна | Обов. | Значення |
|---|---|---|
| `BOT_TOKEN` | ✅ | Токен від @BotFather |
| `OWNER_ID` | ✅ | Ваш Telegram user id (див. `/id`) |
| `SECRET_KEY` | – | Ключ шифрування збережених API-ключів |
| `DATA_DIR` | – | Каталог SQLite та кешу (типово `./data`) |
| `DEFAULT_AI_PROVIDER` / `DEFAULT_AI_MODEL` | – | Типова модель (`anthropic` / `claude-opus-5`) |
| `ANTHROPIC_API_KEY` тощо | – | Ключі через env (імена — як у models.dev) |

## 📦 Розгортання

**Docker (рекомендовано):**

```bash
cp .env.example .env
docker compose up -d --build
```

База SQLite зберігається в `./data`. Запускайте **одну репліку на токен** — паралельний polling Telegram відхиляє (409).

**systemd / PM2:** повний unit-файл — в [основному README](../../README.md#-deployment). Стисло: `pm2 start "npx tsx src/main.ts" --name sotong --kill-timeout 10000`.

## 🔐 Безпека

- API-ключі **шифруються при зберіганні** (AES-256-GCM); задати їх може лише власник і лише в особистих — повідомлення з ключем одразу видаляється.
- Увесь користувацький текст екранується перед показом; системний промпт наказує моделі вважати текст користувачів контентом, а не інструкціями.
- Команди модерації перевіряють статус адміна, не чіпають адмінів і бота, розуміють анонімних адмінів, канали-персони та автопересилання пов'язаного каналу.
- «Читати всі повідомлення» (для `/summarize`) — **явний опт-ін** для кожної групи, типово вимкнено.
- Обмеження частоти на всіх шляхах до ШІ.

**همه چیز داخل تلگرام تنظیم می‌شود**: ‏`/settings` منوی هر گروه را باز می‌کند.
کلیدهای API با پیام خصوصی به بات تنظیم می‌شوند — هرگز در فایل، هرگز در گروه.

## 🚀 شروع سریع

> **پیش‌نیازها:** Node.js ≥ 20 و توکن از [@BotFather](https://t.me/BotFather).

```bash
git clone https://github.com/TegarTheGreat/SotongAssistant.git
cd SotongAssistant
cp .env.example .env        # BOT_TOKEN و OWNER_ID را پر کن
npm install
npm run dev                 # یا: npm start
```

سپس در تلگرام:

1. **به بات پیام خصوصی بده** → ‏`/setkey anthropic sk-ant-…` (فقط مالک؛ پیام فوراً حذف و کلید رمزنگاری‌شده ذخیره می‌شود).
2. **بات را به گروه اضافه کن** و **ادمین** کن (حذف پیام، محدودسازی، دعوت، سنجاق). بدون ادمین همهٔ پیام‌ها را نمی‌بیند (privacy mode).
3. در گروه: ‏`/settings` برای همه چیز، ‏`/aimodel` برای انتخاب مدل.
4. *(اختیاری)* **Business**: در *Settings → Telegram Business → Chatbots* وصل کن.

### پیکربندی

| متغیر | لازم | معنی |
|---|---|---|
| `BOT_TOKEN` | ✅ | توکن @BotFather |
| `OWNER_ID` | ✅ | شناسهٔ تلگرام تو (ببین `/id`) |
| `SECRET_KEY` | – | کلید رمزنگاری کلیدهای ذخیره‌شده |
| `DATA_DIR` | – | پوشهٔ SQLite و کش (پیش‌فرض `./data`) |
| `DEFAULT_AI_PROVIDER` / `DEFAULT_AI_MODEL` | – | مدل پیش‌فرض (`anthropic` / `claude-opus-5`) |
| `ANTHROPIC_API_KEY` و غیره | – | کلیدها از env (نام‌ها مطابق models.dev) |

## 📦 استقرار

**Docker (پیشنهادی):**

```bash
cp .env.example .env
docker compose up -d --build
```

پایگاه SQLite در `./data` می‌ماند. **برای هر توکن فقط یک نمونه** اجرا کن — تلگرام polling موازی را با 409 رد می‌کند.

**systemd / PM2:** فایل کامل در [README اصلی](../../README.md#-deployment). خلاصه: `pm2 start "npx tsx src/main.ts" --name sotong --kill-timeout 10000`.

## 🔐 امنیت

- کلیدهای API **رمزنگاری‌شده ذخیره می‌شوند** (AES-256-GCM)؛ فقط مالک و فقط در خصوصی تنظیمشان می‌کند و پیام حاوی کلید فوراً حذف می‌شود.
- هر متن کاربر پیش از نمایش escape می‌شود؛ پرامپت سیستم به مدل می‌گوید متن کاربران محتواست، نه دستور.
- دستورهای مدیریتی وضعیت ادمین را می‌سنجند، ادمین/بات را هدف نمی‌گیرند و ادمین ناشناس، هویت کانال و بازارسال کانال مرتبط را می‌فهمند.
- «خواندن همهٔ پیام‌ها» (برای `/summarize`) در هر گروه **انتخاب صریح** است و پیش‌فرض خاموش.
- محدودیت نرخ در همهٔ مسیرهای هوش مصنوعی.

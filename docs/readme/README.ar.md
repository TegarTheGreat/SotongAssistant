## 🚀 البدء السريع

> **المتطلبات:** Node.js ≥ 20 وتوكن من [@BotFather](https://t.me/BotFather).

```bash
git clone https://github.com/TegarTheGreat/SotongAssistant.git
cd SotongAssistant
cp .env.example .env        # املأ BOT_TOKEN و OWNER_ID
npm install
npm run dev                 # أو: npm start
```

ثم في تيليجرام:

1. **راسل البوت في الخاص** → ‏`/setkey anthropic sk-ant-…` (للمالك فقط؛ تُحذف الرسالة فورًا ويُخزَّن المفتاح مشفرًا).
2. **أضف البوت إلى مجموعة** واجعله **مشرفًا** (حذف الرسائل، التقييد، الدعوة، التثبيت). بدون إشراف لا يرى كل الرسائل (وضع الخصوصية).
3. في المجموعة: ‏`/settings` لكل شيء، ‏`/aimodel` لاختيار النموذج.
4. *(اختياري)* **Business**: اربطه من *الإعدادات → Telegram Business → روبوتات الدردشة*.

### الإعداد

| المتغير | إلزامي | المعنى |
|---|---|---|
| `BOT_TOKEN` | ✅ | توكن @BotFather |
| `OWNER_ID` | ✅ | معرّفك في تيليجرام (انظر `/id`) |
| `SECRET_KEY` | – | مفتاح تشفير مفاتيح API المخزّنة |
| `DATA_DIR` | – | مجلد SQLite والذاكرة المؤقتة (افتراضيًا `./data`) |
| `DEFAULT_AI_PROVIDER` / `DEFAULT_AI_MODEL` | – | النموذج الافتراضي (`anthropic` / `claude-opus-5`) |
| `ANTHROPIC_API_KEY` وغيرها | – | مفاتيح عبر env (الأسماء وفق models.dev) |

## 📦 النشر

**Docker (موصى به):**

```bash
cp .env.example .env
docker compose up -d --build
```

قاعدة SQLite تبقى في `./data`. شغّل **نسخة واحدة لكل توكن** — تيليجرام يرفض الاستطلاع المتوازي (409).

**systemd / PM2:** ملف الخدمة الكامل في [README الرئيسي](../../README.md#-deployment). باختصار: `pm2 start "npx tsx src/main.ts" --name sotong --kill-timeout 10000`.

## 🔐 الأمان

- مفاتيح API **مشفرة عند التخزين** (AES-256-GCM)؛ يضبطها المالك فقط وفي الخاص فقط، وتُحذف رسالة المفتاح فورًا.
- كل نص من المستخدم يُهرَّب قبل العرض؛ وموجّه النظام يأمر النموذج بمعاملة نص المستخدمين كمحتوى لا كتعليمات.
- أوامر الإدارة تتحقق من صفة المشرف، ولا تستهدف المشرفين أو البوت، وتفهم المشرفين المجهولين وهويات القنوات وإعادة توجيه القناة المرتبطة.
- «قراءة كل الرسائل» (لـ `/summarize`) **اشتراك صريح** لكل مجموعة، مطفأ افتراضيًا.
- حدود تكرار على كل مسارات الذكاء الاصطناعي.

| 🌍 | **Перевод** | `/tr` (ответом) переводит сообщение · `/bridge de` — автоперевод иностранных сообщений для многоязычных групп |

| 🔎 | **Inline и прочее** | `@botname вопрос` — спросить ИИ **из любого чата** · ИИ **знает о себе всё** (версия, команды, настройки чата) · **самообновление** (`/update`, `AUTO_UPDATE=true`) · `/subscription` — Stars-подписки для каналов |
| 🌙 | **Ночной режим и пояс** | `/night 23:00-06:00` ежедневно блокирует группу по местному времени чата (`/settz Europe/Moscow`), с объявлениями и точным восстановлением прав |

| 👑 | **Инструменты админа** | `/promote` `/demote` `/title` · `/warnmode` (mute/kick/ban) · «@admin» зовёт админов · `/tagall` · `/disable` — отключение команд · `/antilink off\|invites\|all` + `/allowlink` · темы форума (`/newtopic` и др.) · welcome и goodbye с плейсхолдерами `{mention}` `{count}` |
| 🌐 | **10 языков** | Автоопределение по Telegram пользователя, переопределение на чат через `/lang` |

**Всё настраивается внутри Telegram**: `/settings` открывает инлайн-меню группы
(приветствие, капча, ИИ, эфемерные ответы, антифлуд, чтение контекста, лимит
предупреждений, язык). API-ключи задаются в личке боту — никогда в конфиге и
никогда в группе.

## 🚀 Быстрый старт

> **Требуется:** Node.js ≥ 20 и токен от [@BotFather](https://t.me/BotFather).

```bash
git clone https://github.com/TegarTheGreat/SotongAssistant.git
cd SotongAssistant
cp .env.example .env        # заполните BOT_TOKEN и OWNER_ID
npm install
npm run dev                 # или: npm start
```

Затем в Telegram:

1. **Напишите боту в личку** → `/setkey anthropic sk-ant-…` (только владелец; сообщение сразу удаляется, ключ хранится зашифрованным).
2. **Добавьте бота в группу** и сделайте **админом** (удаление сообщений, ограничения, приглашения, закрепы). Без прав админа бот не видит все сообщения (privacy mode).
3. В группе: `/settings` — всё, `/aimodel` — выбор модели ИИ.
4. *(Опционально)* **Business**: подключите бота в *Настройки → Telegram Business → Чат-боты*.

### Конфигурация

| Переменная | Обяз. | Значение |
|---|---|---|
| `BOT_TOKEN` | ✅ | Токен от @BotFather |
| `OWNER_ID` | ✅ | Ваш Telegram user id (см. `/id`) |
| `SECRET_KEY` | – | Ключ шифрования сохранённых API-ключей |
| `DATA_DIR` | – | Каталог SQLite и кэша (по умолчанию `./data`) |
| `DEFAULT_AI_PROVIDER` / `DEFAULT_AI_MODEL` | – | Модель по умолчанию (`anthropic` / `claude-opus-5`) |
| `ANTHROPIC_API_KEY` и др. | – | Ключи через env (имена — как в models.dev) |

## 📦 Развёртывание

**Docker (рекомендуется):**

```bash
cp .env.example .env
docker compose up -d --build
```

База SQLite сохраняется в `./data`. Запускайте **одну реплику на токен** — параллельный polling Telegram отклоняет (409).

**systemd / PM2:** полный unit-файл — в [основном README](../../README.md#-deployment). Кратко: `pm2 start "npx tsx src/main.ts" --name sotong --kill-timeout 10000`.

## 🔐 Безопасность

- API-ключи провайдеров **шифруются при хранении** (AES-256-GCM); задать их может только владелец и только в личке — сообщение с ключом сразу удаляется.
- Весь пользовательский текст экранируется перед выводом; системный промпт велит модели считать текст пользователей контентом, а не инструкциями.
- Команды модерации проверяют статус админа, не трогают админов и бота, понимают анонимных админов, каналы-персоны и автопересылки связанного канала.
- «Чтение всех сообщений» (для `/summarize`) — **явный опт-ин** для каждой группы, по умолчанию выключено.
- Лимиты частоты на всех путях к ИИ.
